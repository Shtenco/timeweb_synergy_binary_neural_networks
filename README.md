# timeweb_synergy_binary_neural_networks

**SYNERGY / HIAI — исследование №02: Бинарные нейросети на CPU**

> **Статус:** Реальные разведочные измерения. Репозиторий содержит исследовательскую документацию; полнота синхронизации всех исходных файлов проверяется отдельно. Название Timeweb в пути не означает официального одобрения проекта компанией.

## Задача исследования

FP32/BNN, UCI Digits, упаковка бинарных весов и timing. Проверяем не только средние показатели, но и воспроизводимость, ошибки методики, границы применимости и альтернативные объяснения наблюдаемого эффекта.

## Экспериментальная гипотеза

Сравнить поведение подходов в одинаковых контролируемых условиях. Для каждой проверки должны быть зафиксированы входные данные, версия кода, seed, железо/ОС, число повторов, сырые результаты и критерий успеха. Непроведённые проверки и синтетику нельзя выдавать за реальные эксперименты.

## Воспроизведение (после синхронизации исходников)

```bash
git clone https://github.com/Shtenco/timeweb_synergy_binary_neural_networks.git
cd timeweb_synergy_binary_neural_networks
python -m venv .venv
# Linux/macOS: source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m prototypes run 02 --seed 42 --out results/local
```

Команды предназначены для локального запуска и могут требовать установки PyTorch CPU, дополнительного датасета или компилятора C++; **успешное выполнение CI в данном репозитории не подтверждено**.

## Доказательная база и ограничения

**Что исследовано:** FP32/BNN, UCI Digits, упаковка бинарных весов и timing.

**Что остаётся недоказанным:** Вычисления в Python не эквивалентны оптимизированному XNOR/popcount ядру; один небольшой датасет.

Прозрачная публикационная проверка требует повторов на независимых seed и при необходимости на новых датасетах, сохранения всех исходных таймингов, проверки корректности и предупреждения об отклонениях (например, ошибочном NumPy-тайминге в ранних прогонах №07). Отрицательные результаты — полноценные данные.
